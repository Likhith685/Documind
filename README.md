# DocuMind
Ask questions about your PDFs and get answers with page citations. Everything runs on your machine — no API keys, no uploads to anyone's cloud.

## Tech stack
- Python 3.10+
- PyMuPDF
- LangChain
- sentence-transformers (BAAI/bge-small-en)
- FAISS
- Ollama
- FastAPI + Uvicorn
- Pydantic
- HTML / CSS / JavaScript
- Rich
